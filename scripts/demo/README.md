# Demo scripts

- `run_yessoda_serial_demo.sh`: end-to-end standalone demo entrypoint.
- `align_qwen_fa_serial_demo.py`: occurrence-aware R0/R1/R2 full and serial-window inference.
- `render_qwen_fa_karaoke.py`: ASS KTV subtitles, 12 individual videos and 7 comparison videos.

The demo is metric-free and must not be used to select checkpoints.  Its outputs stay under the input song directory rather than under tracked project results.
