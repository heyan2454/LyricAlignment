## 分项证据

### 重训是否有效

- 结论：**从官方底座重训有效，但需要步数**；早上那次「重训≈旧模型」的判断是错的（当时只能评到 step 1100–1450，中层名额被早期存档吃光）。
- 训练器全量口径边界 MAE：47.16 ms → 43.87 ms（-3.29 ms）；
- joint@80ms：88.74% → 89.50%；零长度率 0.78% → 0.72%；
- 逐字符配对（同一批字符）：300 条样本 -6.84 ms（z=-2.7）；**1200 条大样本 -4.21 ms（z=-4.97，n=9397）**，长字符 -7.99 ms（z=-1.86，方向更大但功效不足）；
- 教训（已写进漏斗修复）：**选点集合被预算饿死会直接产出错误的科学结论**。

### 误差集中在哪里

- 结论：**误差集中在长音符**，且随标注时长单调上升（旧 r2/750，1200 条 / 9,397 字符）；
- 各时长桶超 0.2s 率：0-0.25 1.7%，0.25-0.5 1.8%，0.5-1 4.1%，1-1.5 7.0%，1.5-2 8.7%，2-3 12.4%，3.0+ 7.7%；
- 更正记录：早先 300 条小样本给出的 ≥2s 超差率 24.6% 是小样本高估（n=57, SE 5.6pp），**以 12.4%（n=178）为准**。

### 天花板是不是任务不可测（Track 1）

- 标签派生**忠实**（20,298 条全量审计：起止差中位 20 ms、最大 40 ms，即半格），所以天花板不是我们管线造成的；
- 长字符结束点**声学无证据**比例 37.0% vs 短字符 4.0%；
- 但失败字符里只有 12.5%（占全部字符 0.51%）落在不可测边界上 ⇒ **约 7/8 的失败是有证据的真实模型错误**；
- 因此「改评测口径」只能回收 ~0.5% 绝对指标，降级为配角；主线是模型本身。

### 长音符失败机制（配对 + 置信度 + 约束解码）

- 配对（1200 条 / 9,397 字符）：全部字符 -4.2 ms（z=-4.97，显著）；长字符起始点 z=-2.68 已显著，长字符结束点 z=-1.25 方向好但功效不足；
- 长音符失败的本质是**没把握 + 系统性偏早**：≥2s 失败时 top-1 概率中位 0.239、熵 3.08 nats、带符号误差 -710 ms；
- 约束解码不是只修结构：短字符结束点 -3.6 ms（z=-4.49），超容差率 1.53% → 1.07%。

### 标注结构：长音符结束点是什么类型的边界

- 只读 M4Singer TextGrid 本体（20896 个文件 / 193666 个字符区间）：**字符结束点是「声音→静音」型边界的比例随时长单调上升**；
- 各桶：0-0.25s 23.4%，0.25-0.5s 27.2%，0.5-1.0s 43.1%，1-2.0s 77.0%，2-+s 91.5%；
- 含义：长音符的结束点在标注上就是「声音消失到哪里算结束」的约定，而起始点仍是有事件可参照的边界（不随时长变化）⇒ 与「无声学证据」「失败偏早」两项测量互相咬合。

### 机制定位：时长回归到常见值

- **全体统计看起来一切正常**（各桶时长比 0.99–1.04、≥2s 中点位移仅 30 ms），只有把失败子集单独拿出来才看得见机制；
- 长音符失败子集：时长比 **0.709**（被压短）、中点偏早 -328 ms；而短字符失败子集被拉长（2.533）且偏晚（+132 ms）；
- 比值随标注时长**单调下降** ⇒ **时长回归到常见值**：模型不确定时把区间长度拉回语料里最常见的 0.4–0.6 s。这排除了「加长音先验/正则」一类模糊解释，直指训练暴露。

### 重排的上界：容差窗口内的概率质量

- **长音符失败无法靠重排救回**：失败子集落在标注 ±0.2s 内的概率质量中位只有 0.14–0.20，几乎没有一例超过 0.5 ⇒ 是信念整体错位，不是排序没排好；
- 对照命中情形（质量中位 0.93–0.99）：模型多数时候自信且正确，失败时自信地错在别处；
- 测量行数 3334，判决行示例：offset|0-0.5s|miss n=11 质量 0.24；offset|0.5-1s|miss n=16 质量 0.165；offset|1-2s|miss n=14 质量 0.202

### 排名会高估解码空间（校正项）

- 只看排名会**高估**解码侧空间：≥2s 结束点失败的中位排名只有 7、69% 的失败真值仍在前 10 名；
- 但排名不含时间距离，必须与 `mass_in_tolerance` 一起读 —— 后者给出的判决是重排无效。本报告就是那条校正项。

### 邻接先验（后被 DP 吸收）

- 借相邻字起始点当本字结束点：可用字符 7473 个，超容差率 2.05% → 1.23%，配对差 -6.76 ms（z=-5.76）；

### 跨窗共识：负结果

- **平移多窗共识显著更差**：同一批被≥2窗覆盖的字符上，owner 单窗 0.9716 vs 共识 0.9424，配对差 +18.7 ms（z=9.9），更好/更差 2211/2097；

### 真歌批塌陷画像与 DP 的真实作用

- 真歌批（33 首 / 13735 字）三种时间轴的零长度率：模型 raw **10.80%** → 上游 `_fix_timestamps` 后 **16.28%** → GPU 侧定向修补后 0.00%；
- **上游修补是净负贡献**：31/33 首被放大，平均 +5.55 pp；
- 真歌上 DP 只修合法性、不修精度：它被迫选择的合法终点在声学证据上更高的比例只有 46.2%（ΔRMS）/ 51.2%（谱通量）≈ 抛硬币；另有 15.0% 的塌陷字在 top-8 里根本没有合法终点；
- ⇒ **DP 会让结构检查全部变绿而错误仍在**，所以必须与置信度门控同时上线。

### 置信度门控（可交付）

- 域内（18803 次测量，错误率 1.55%）判别「会不会超差」的 AUC：熵 0.9336、top-5 质量 0.9452、top-1 0.8963、标注名次 0.9786（需真值，只能当 oracle）；
- 真歌批（无真值，预测零长度 10.80%）：熵 AUC 0.9227 / 0.9181，边际 0.8827；
- **按歌留一交叉验证**（阈值不用被评那首歌自己决定）：复核 10pct 消除 55% 缺陷、剩余 5.43%；复核 20pct 消除 82% 缺陷、剩余 2.40%；复核 5pct 消除 34% 缺陷、剩余 7.60%；
- 已做成可交付工具：`export_review_gating.py` 对 33 首 / 13735 字实跑，标记 10.75% 的字 → 抓到 55% 缺陷，剩余缺陷率 5.43%（原 10.80%）；
- 结论：**模型能自己说出哪里不可信，且跨歌泛化**；这是产品一直缺的自动质检门。

### 事后校准（时长 + 中心）：失败

- 留出歌交叉验证的事后仿射校准（按预测时长分桶映射到真值中位；越界策略：identity（超出拟合节点范围时不做修正；旧版钳位造成 ≥2s 桶伪影））：
  all 2.60% → 无条件校准 2.63%（均差 +0.28 ms）；≥2s 桶 10.23% → 10.70%；按模型熵条件化反而把 ≥2s 推到 18.60%
- ⇒ **事后校准没有收益**（无条件≈中性，条件化对长音有害），该路径关闭；
- 原因：诊断到的「压短 + 偏早」是**失败子集的条件性偏差**（全体中点位移只有 20–30 ms，失败子集才 −328 ms），拿全体中位数去修会把本来正确的九成一起挪坏；
- **口径更正记录**：本节先前给出的「≥2s 10.23% → 37.67%（灾难性）」大部分是**我自己实现的钳位伪影**（预测时长超出拟合节点时被拉回最后一桶中位数）。改成「越界即不修正」后真实结果是 10.23% → 10.70%。结论方向（无收益）不变，但量级被夸大了 —— 已在脚本 v2、测试与预注册中一并更正。
