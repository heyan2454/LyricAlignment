# 边界声学证据：长音符的字符边界是不是可听见的事件（生成，勿手改）

> 由 `scripts/evaluation/measure_boundary_acoustics.py` 生成；样本 = 最富含长音符的 400 条，长字符 2420 个，共 11338 次边界测量，上下文 ±60ms。

## 方法（不含模型）

对每个字符边界，取两路声学新颖度信号（谱通量、|ΔRMS|），比较**边界 ±context 内的峰值**与**同一音符靠内侧窗口的中位值**（长音符内部就是持续音本身）：

```
prominence = (边界附近峰值 − 音符内侧中位值) / 该条目新颖度的全局中位数
```

关键设计：内侧窗口只取音符**自己那一侧**。若取对称窗口，音符结束后的**下一个音的开始**（强事件）会被算进基线，使所有音符结尾都显得不突出——第一版就踩了这个坑。指标「无高于内部的比例」表示边界处的新颖度峰值甚至没有超过音符内部，即**该边界在声学上不可分辨**。

## 结果

| 通道 | 边界类型 | 长字符（≥1.0s） | 短字符（对照） |
|---|---|---|---|
| 谱通量 | 起始 onset | 13.8%（p50 3.28） | 10.1%（p50 3.72） |
| 谱通量 | **结束 offset** | **28.9%（p50 1.09）** | 13.5%（p50 2.98） |
| ΔRMS | 起始 onset | 6.9%（p50 9.80） | 6.2%（p50 10.38） |
| ΔRMS | **结束 offset** | **19.6%（p50 6.32）** | 4.1%（p50 9.83） |

## 读法

- **长音符的开始**与短音符一样清楚（13.8% vs 10.1%），说明长音符难不是整体性的；
- **长音符的结束**明显更模糊：谱通量口径下 28.9% 的标注结束点在声学上与音符内部无法区分（短音符 13.5%），ΔRMS 口径下为 19.6% vs 4.1%；中位突出度只有短音符的约 1/3（1.09 vs 2.98）；
- 这与我们的指标口径直接相关：指标取 max(|Δ起始|, |Δ结束|)，结束点的固有歧义会被直接放大成误差。

## 边界与下一步

- 本步骤**不含模型**，因此只能证明标注在这些位置本身缺证据，还不能证明模型预测落在真实事件上；
- 决定性检验（Track 1 步骤②b，需要模型逐字预测）：在同一批长音符的结束点上，比较**模型预测边界**与**标注边界**各自的声学突出度。若预测显著更突出 ⇒ 现行指标在惩罚正确行为（H1 成立）；若两者都低 ⇒ 歧义不可约，正确做法是可容许边界评测与标签口径，而不是继续训模型。
