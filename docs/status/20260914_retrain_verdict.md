## 结论

1. **重训有效，但幅度小、且需要步数**：训练器全量口径 MAE 47.16 ms → 43.87 ms（-3.29 ms，-7.0%），joint@80ms +0.76 pp；
2. 测试口径（0.2s 命中率，歌平均）中层复评：旧 750 = 0.9561，新 run 最好 = 0.9648（+0.87 pp）；
3. **早上那句"重训≈旧模型"是错的**：当时只能评到 step 1100–1450（训练内漏斗的 L2 名额被早期存档吃光）。逐字符配对现在给出全部字符 -6.8 ms（z=-2.7），长字符 -14.1 ms（z=-1.1，n=378，功效不足），短字符结束点 -4.8 ms（z=-2.35） ⇒ 长音符改善更大但样本不够，**长音符仍是未解决的靶子**；
