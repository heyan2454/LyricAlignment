# 触发器跨语料复现：M4Singer 否证了间隙残余，只有置信度勉强同向（第 30 轮，2026-09-12）

> 数字由 `runs/20260912_trigger_replication/REPLICATION.json` 生成。两个语料用**同一份代码路径**算间隙特征与十分位。零新前向、零 GPU。
> M4Singer 侧标签是 **rule_validated 弱标签（80ms 量化）**，时间线由真实片段**拼接**而成（含人工静音）；GTSinger 是人工词级真值 + 连续清唱片段。

## 0. 结论：`gap_over_core` 是语料特异信号，不能上线

- GTSinger（n=4,288）：Spearman ρ = **+0.7774**，十分位中位滞后跨度 **483.0ms**，「真值晚于预测」比例 66.5%
- M4Singer（n=4,241）：ρ = **-0.0602**（即无相关），跨度只有 **97.0ms**，「真值晚于预测」比例 30.1%（方向都相反：M4 的中位滞后是 **-115.5ms**，即预测**偏晚**）
- AUC 也不能救它：M4 上 `gap_over_core` 对「切早」的 AUC = 0.5059（≈抛硬币），而标签流行率高达 65.7% ⇒ 近常数标签下 AUC 无意义，所以本轮同时给出十分位/ρ 的抗饱和诊断。
- **唯一勉强跨语料同向的是置信度**：M4 上 `end_entropy` 对「误差>100ms」AUC = 0.6619（train 0.6763 / val 0.6392），方向与 GTSinger 一致但明显更弱（GTSinger 端点误差 AUC 0.845）；且它对滞后大小**无排序力**（M4 ρ = 0.0555）。
- `margin` 在 M4 上 AUC = 0.3966（<0.5，方向与直觉相反）⇒ **第 27 轮的融合分数里，真正可移植的成分只有熵**；间隙残余必须降级为「GTSinger 连续清唱片段上的局部现象」。

## 3. 这会改变什么

- **上线判定**：`gap_over_core` **不得**作为通用重解码触发器；只可作为 GTSinger 型（连续清唱、单段录音）数据的局部诊断，或等它在真实拼接/伴奏数据上被重新证明。
- **第 29 轮的预算表要加限定**：那张表的触发器包含间隙残余，属于 **GTSinger 口径**；只用熵的对应数字（同一轮 JSON 里的 entropy-only）为 5%/10%/20% = +1.12/+2.51/+4.90pp（全视图可达上界），与融合值接近 ⇒ **预算结论本身不因间隙降级而改变**，但实现时应只用熵。
- **方法学**：跨语料复现必须同时看 AUC **和**抗饱和的连续量排序——M4 的近常数标签会让 AUC 一律接近 0.5，只报 AUC 会得出「什么都没用」的错误结论，只报 ρ 又可能掩盖覆盖率差异；两者并报才能定位到底是**信号没了**还是**标签变了**。
